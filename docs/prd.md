# 需求文档

## 1. 应用概述

**应用名称**：单词图片识别工具

**应用描述**：用户上传包含英语单词的图片，应用通过OCR识别图片中的单词，自动查询每个单词的音标和中文翻译，生成表格展示结果，支持导出表格。

## 2. 页面结构与功能说明

### 2.1 页面结构

```
单词图片识别工具
└── 主页面
    ├── 图片上传区域
    ├── 识别结果展示区域
    └── 导出功能区域
```

### 2.2 主页面功能说明

#### 2.2.1 图片上传区域

- 用户可点击上传按钮选择本地图片文件
- 支持多张图片同时上传
- 上传后显示图片缩略图预览
- 用户可删除已上传的图片
- 提供「开始识别」按钮触发OCR识别

#### 2.2.2 识别结果展示区域

- 以表格形式展示识别结果
- 表格列包含：单词、音标、中译
- 每行对应一个识别出的单词及其信息
- 多张图片的识别结果合并展示在同一表格中

#### 2.2.3 导出功能区域

- 提供「导出表格」按钮
- 点击后将当前表格内容导出为文件

## 3. 业务规则与逻辑

### 3.1 OCR识别规则

- 对上传的每张图片执行OCR识别
- 提取图片中的英语单词文本
- 识别结果按单词进行分词处理

### 3.2 单词查询规则

- 对识别出的每个单词查询音标和中文翻译
- 查询结果填充到表格对应列中

### 3.3 结果合并规则

- 多张图片的识别结果按上传顺序依次合并到表格中
- 相同单词重复出现时，每次出现均作为独立行展示

### 3.4 导出规则

- 导出文件包含表格的全部内容
- 导出格式为常见表格文件格式

## 4. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户未上传图片直接点击「开始识别」 | 提示用户需先上传图片 |
| 图片中未识别到任何单词 | 提示「未识别到单词」 |
| 单词查询失败（无音标或翻译） | 对应列显示为空或显示「查询失败」 |
| 用户在无识别结果时点击「导出表格」 | 提示用户需先完成识别 |

## 5. 验收标准

1. 用户上传一张包含英语单词的图片
2. 点击「开始识别」按钮
3. 页面展示表格，包含识别出的单词、音标、中译
4. 点击「导出表格」按钮
5. 成功下载包含表格内容的文件
